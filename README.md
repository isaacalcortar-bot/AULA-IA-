# AULA IA — Sitio web

Sitio estático para la colección AULA IA de Isaac Alcorta Ramírez.

## Publicación gratuita recomendada
GitHub Pages. Como alternativa, Cloudflare Pages o Netlify.

## Estructura
- `index.html` — página principal
- `styles.css` — identidad visual y responsive
- `script.js` — menú móvil y botón copiar prompt
- `assets/covers/` — portadas de las guías
- `assets/img/` — imagen del autor
- `downloads/` — PDFs de la colección

## GitHub Pages
Sube todos los archivos a un repositorio público y activa Pages desde Settings → Pages → Deploy from branch → main / root.
